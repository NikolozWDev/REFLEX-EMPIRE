# REFLEX EMPIRE

A browser-based aim training game designed to improve mouse control, reaction time, and target accuracy for FPS and competitive shooter players.

REFLEX EMPIRE provides a lightweight practice environment where players can develop faster reflexes and more consistent cursor precision through simple, repeatable training sessions.

## Website

**Play Online:**  
https://nikolozwdev.github.io/simple-game/

## About

The project was built as a frontend application focused on creating an engaging aim training experience with responsive gameplay and immediate visual feedback.

The game emphasizes smooth interactions, accurate mouse tracking, score progression, and quick reaction challenges that help players improve core aiming mechanics used in modern shooter games.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Running Locally

Clone the repository:

```bash
git clone https://github.com/NikolozWDev/simple-game.git
```

Move into the project directory:

```bash
cd simple-game
```

Open `index.html` in your preferred browser.
